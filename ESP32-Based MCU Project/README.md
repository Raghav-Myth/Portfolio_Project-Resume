# ESP-32-Based-Microcontroller
Custom ESP32 development board with integrated Wi-Fi/Bluetooth connectivity, onboard IMU sensing, and I²C interfaces for peripheral expansion and embedded systems applications.
For further information on design and capabilities of the board please refer to the file "ESP32 Based Microcontroller.pdf". 

Note: The current Gerber files require revision before fabrication. The original design utilizes blind and buried vias, which are not supported by the target PCB manufacturer. An updated version optimized for standard manufacturing processes will be released in a future update.
